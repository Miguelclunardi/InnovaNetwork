# free5GC — optional core

Installer of the InnovaNetwork **free5GC** core (namespace `free5gc`).

```bash
sudo ./free5gc/setup-gtp5g.sh     # once: UPF kernel module
./free5gc/install.sh              # install (no sudo)
./free5gc/test.sh                 # test with UERANSIM
```

Full documentation: [docs/components/free5gc.md](../docs/components/free5gc.md). Core switch:
[tutorial 5](../docs/tutorials/05-switch-core.md).
