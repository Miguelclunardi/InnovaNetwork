gNB OCUDU 

          
O serviço do gNB ainda não foi instalado no host do gNB.
            Rode uma vez, a partir da máquina do core:

            scp scripts/ocudu/setup-gnb-service.sh innovaserver@10.10.0.1:/tmp/ && ssh -t innovaserver@10.10.0.1 sudo bash /tmp/setup-gnb-service.sh

          

          

          

            
            
          

          

          

            
            
            
          

          
Saída do serviço (journal)
            

          
A máquina já deve estar preparada (interface, VF do DPDK, XDP, PTP): o botão só roda
            taskset … ./gnb -c configs/<arquivo>.yml como serviço. Parar = Ctrl+C no gNB.

        

        

          
UERANSIM (gNB e UEs simulados) 

          

            
            
            
          

          

        

        
Ações recentes
    
      
    
    
    
    
    Parar = escala 0 (nada é apagado). Reiniciar recria o pod e também os que dependem dele (UPF → SMF; AMF → gNB e UEs
      simulados). "Iniciar tudo" sobe em ordem: MongoDB → NRF → SCP → demais → UPF → SMF → AMF → gNB UERANSIM → UEs, conferindo a
      fibra no AMF/UPF, o PFCP e o NG Setup; um pod que suba sem a fibra é recriado sozinho.
    
  
    

  
    
    
    
    
    
      
    Configuração (config.env)
    
      
    Edita o config.env da máquina do core. Precisa da senha de administrador
        (mostrada no fim do sudo ./install.sh; também em sudo cat /opt/open5gs-k3s/state/dashboard-admin-password).
    
      
    
        
        
      
    
    
    
    
    
      
    
        
        
        
        
        
        
        
        
        
      
    
      
    Salvar só grava o arquivo (com backup e a mesma validação do install). Aplicar
        continua sendo o comando sudo ./install.sh … na máquina do core — o painel mostra qual.
